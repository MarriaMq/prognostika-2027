# Аналитика «Прогностика 2027»

Каждое действие человека (бот, мини-апп, оплата) по его Telegram ID попадает в Google-таблицу «Прогностика 2027 · Аналитика». Там готовы листы: Сводка, Сегменты, Контент, По дням.

```
мини-апп ── POST /api/track ──► сервер бота ──(раз в 5 сек, пачкой)──► Apps Script ──► Google-таблица
бот, monoPay ── trackServer() ──┘
```
Мини-апп в Google напрямую не ходит. Секрет таблицы есть только у сервера.

## Что сделать Денису (около 30 минут)

1. **Скрипт в таблицу.** Открыть таблицу → Расширения → Apps Script. Вставить `apps-script/Code.gs` целиком и сохранить.
2. **Секрет.** В Apps Script: Настройки проекта → Свойства скрипта → добавить `SECRET` = длинная случайная строка.
3. **Опубликовать.** Начать развёртывание → Веб-приложение. Выполнять от имени: «Я». Доступ: «Все». Скопировать URL `…/exec`.
4. **Сервер.** Подключить `server/analytics.js` (Node 18+, без зависимостей). Переменные окружения: `BOT_TOKEN`, `SHEETS_WEBHOOK_URL` (URL из п. 3), `SHEETS_SECRET` (секрет из п. 2).
5. **Маршрут** `POST /api/track` → `handleTrack(req.body)`, ответ 204. Пример есть в комментарии в файле.
6. **События бота и оплаты.** Вызвать `trackServer()` в шести местах: /start, ссылка-доступ, создан счёт, оплата прошла, оплата не прошла, блокировка бота (403). Список с параметрами лежит в `analytics.js`.
7. **Мини-апп.** В `v5/index.html` указать `TRACK_URL` (адрес бэкенда). Если бэкенд на другом домене, дописать этот домен в CSP `connect-src`.
8. **Проверка.** Открыть мини-апп в Telegram и пройти пару экранов. Через 5–10 секунд на листе «События» появятся строки.

## Важно
- Демо-данные (колонка «Демо» = 1) удалятся сами при первом настоящем событии.
- Если строки в «Пользователи» правили руками, то в таблице: меню «Прогностика» → «Пересобрать „Пользователи“».
- Дата рождения в аналитику не уходит, только возраст. Доступ к таблице давать только клиентке и Денису: там имена и username.
- Цены и факт оплаты в таблицу пишет только сервер (`payment_success` после вебхука monoPay). Клик «Оплатить» из мини-аппа означает только попытку.

## Листы таблицы
| Лист | Что показывает |
|---|---|
| Сводка | период (Сегодня / Вчера / 7 / 30 дней / Всё время), новые люди, оплаты, выручка, средний чек, воронка по шагам, оплаты по тарифам, кому стоит написать |
| Сегменты | выбираешь статус, видишь список людей (свежие сверху) |
| Контент | какие месяцы открывают, общий или личный год, какие разделы раскрывают, откуда приходят и сколько платят |
| По дням | 30 дней: новые, регистрации, тарифы, попытки, оплаты, выручка, активные, график |
| Пользователи | одна строка на человека со статусом, ведёт скрипт |
| События | сырой журнал всех действий |
| Справочник | что означает каждое событие и статус |
