# Тексты прогностики

Здесь лежат все тексты прогнозов. Приложение берёт их отсюда само, без ИИ: по дате рождения считает аркан и открывает нужный файл.

## Где какой текст

```
texts/
  year/                      годовой прогноз
    general/                 общий прогноз (карьера, бизнес, финансы), вкладка «Общий»
      ru/                    русский
        female/01.md … 22.md женщины, аркан 1 … 22
        male/01.md … 22.md   мужчины
      uk/                    украинский
        female/ …
        male/ …
    personal/                личный прогноз (любовь, семья), вкладка «Личный»: тексты ещё ждём
```

Пример: общий годовой прогноз, украинский, мужчины, 7 аркан → `year/general/uk/male/07.md`.

## Как устроен файл

```
# 7 аркан — Колесница

## Общий фон

Первый абзац.

Второй абзац. **Жирный текст** выделяется двумя звёздочками с двух сторон.

## Карьера и бизнес
…
```

- `#` — заголовок файла (номер и название аркана). В приложении не показывается, он нужен, чтобы быстро найти файл.
- `##` — название рубрики. Именно так оно будет написано на карточке.
- Абзацы разделяются пустой строкой.
- `**текст**` — жирное выделение.

Рубрики в общем прогнозе: Общий фон, Карьера и бизнес, Финансы, Риски и сложности (UA: Головні тенденції року, Кар’єра та бізнес, Фінанси, Ризики та труднощі).

## Как заменить текст

1. Найди файл по пути выше.
2. Поправь текст, сохрани. Кодировка UTF-8, формат и пустые строки не ломать.
3. Залей на сервер. Код приложения менять не нужно.

Проверить, что все файлы на месте и в каждом 4 рубрики: `node v5/texts/check.mjs`.

## Формулы (зашиты в `index.html`, функции `arcGeneral` и `arcPersonal`)

Если результат больше 22, отнимаем 22, пока не станет от 1 до 22.

- **Общий:** число рождения + месяц рождения + сумма цифр года. 28.10.1998 на 2027: 28 + 10 + 11 = 49 → 5.
- **Личный:** сумма всех цифр даты рождения + сумма цифр года. 28.10.1998 на 2027: 38 + 11 = 49 → 5.
- Год в формуле — год, в котором начинается личный год: период 2026–2027 считается с 2026 (10), период 2027–2028 с 2027 (11).

Источник: PDF клиентки «Годовой общий прогноз» для женщин и мужчин, RU и UA (26.11.2026). Жирные выделения перенесены из PDF. Названия арканов на украинском в заголовках файлов добавлены нами, в приложении их не видно.
